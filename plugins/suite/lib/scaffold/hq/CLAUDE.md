# The hq of this tree

This repo holds what spans the repos in this folder. Their code stays in their own repos.

- Settled: `DECISIONS.md`. `agentik decisions show N` reads one entry, and `agentik decisions render` writes the block below.
- Open work: `HANDOFF.md`, in build order. A finding that blocks nothing: `NICE_TO_HAVE.md`.
- A question for the owner: `agentik decisions new` files it in `OPEN-QUESTIONS.md`.
- Before a commit: `make check`.
